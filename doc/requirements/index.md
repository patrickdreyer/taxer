# Requirements
This section contains all requirements for the Swiss Crypto Tax Helper application, organized in a three-tier structure for full traceability.

## Structure
The requirements follow a hierarchical approach:

- **Product Requirements (PRQ)** - High-level product capabilities and features that define what the product should do
- **Customer Requirements (CRQ)** - User-focused requirements derived from product requirements that specify how users will interact with the system
- **Technical Requirements (TRQ)** - Implementation-specific requirements derived from customer requirements
